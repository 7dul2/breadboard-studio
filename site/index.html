WORKFLOW · 01–06
01

选板、拼板、改尺寸

400 / 830 孔面包板、可拆拼装式、洞洞板。拖把手就能延长或裁剪行列；拼接时按 2.54 mm 栅格对齐。

BoardDefinition · spliceable · custom size
02

从目录放元件，而不是画方块

主控、显示、传感器、输入、电源都有带引脚角色与证据状态的定义。搜索支持中文别名与料号。

catalog · pin_meta · featured / fold
03

手工接线，或自动排线

拖线、改端点、换颜色。多选后自动规划电源 / 地 / I²C / GPIO，会报告走线长度与待审核项。

autowire · corridor-aware · revision-safe
04

校验说人话，不吓人

短路、浮空输入、I²C 地址冲突、未上电、保留引脚……点击结果就能定位到画布上的对象。

rules · needs_review · honest unknowns
05

在沙箱里真跑程序

QuickJS + 虚拟时钟：GPIO、I²C、传感器驱动、串口、网络时间线与断点。同样输入可录制回放。

sim package · recording · breakpoints
06

导出到实物工作台

SVG / PNG 含图例与徽标；JSON / DSL 可往返；接线步骤可给搭板的人照着做。实机模式可看串口（不烧录）。

export · steps · Web Serial

给人用，也给 Agent 用

CLI · MCP · 同一引擎 
# 校验一份设计（error 时退出码 1）
pnpm bb validate design.breadboard.json --json

# 自动排线，先 dry-run 再写回
pnpm bb autowire design.breadboard.json \
  --host mcu --components sht41,bmp390 \
  --dry-run --json

# 把同一引擎挂成 MCP 工具
node packages/cli/bin/bb.mjs mcp
  • 默认只读 autowire / apply 不带 write 就不落盘；写入可用 expected_revision / hash 防并发冲突。
  • 两种失败分清 设计里有 error 是调用成功；用法或事务错误才是真失败。
  • 不另起一套语义 MCP 工具返回体就是 CLI --json 载荷，shell 和 Agent 不会漂移。
  • 文件是事实来源 没有云端私有格式；JSON / DSL / SVG 都能进版本库。

诚实边界

宣传站也该像目录一样说实话——这是仓库的一贯约定：

  • 内置几何目前多为 approximate / unknown，不是「已实测 verified」。
  • 仿真覆盖 GPIO、I²C、若干传感器与显示；没有 ADC / PWM / OneWire，也没有真实固件。
  • 「实机」模式只读串口并可复位，不能烧录。
  • Studio TS 只做语法转译，不做类型检查。
