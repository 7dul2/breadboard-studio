Breadboard Studio

在浏览器里拼面包板或洞洞板、摆元件、自动接线，再按图搭建你的电路。

一个开源的面包板与洞洞板布局工具。你可以直接操作画布，也可以让 AI Agent 通过 CLI 和 JSON 设计文件参与搭建——两种方式共用同一套孔位、导通关系和校验规则。无需安装或登录。

可以做什么

  • 按实物结构拼板：一体式 400 / 830 孔面包板、可拆拼装式，以及 5×7 cm、7×9 cm 洞洞板。
  • 洞洞板每个镀锡焊盘默认独立不导通，元件可直接焊在孔位，画布可在元件面与焊接面之间切换。
  • 点击孔位查看同组孔与整个导通网络的高亮，检查连接关系。
  • 多选主控与外设后自动排线，按引脚角色规划电源、GND、I²C 与 GPIO，可选择杜邦线或硬质跳线。
  • 静态校验会报告同孔冲突、脱格、板体碰撞和电源对地短路。
  • 接线向导按线号逐根列出两端孔位与颜色，并保存完成进度。
  • 设计导出为 .breadboard.json，也可以导出 SVG 或 PNG 分享布局。
  • 在隔离沙箱里真实执行主控程序：驱动板载 RGB、打印串口、经真实 I²C 总线把画面写进 OLED。

支持的元件

内置 ESP32-S3 N16R8、XIAO ESP32-S3 Sense、0.96 英寸 SSD1315 OLED、KY-040 旋转编码器、轻触按键、TTP224 触摸模块、SHT41 / BMP390 / LTR390 / SEN66 传感器与供电模块等；也可以在元件库导入自定义定义，无需修改应用代码。
